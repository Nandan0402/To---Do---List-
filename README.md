# 📝 To-Do List Web App

## 📌 Overview
This is a simple and user-friendly **To-Do List web application** built using **HTML, CSS, and JavaScript**.  
It helps users manage their **daily tasks efficiently** by allowing them to add, complete, and delete tasks.

The project is ideal for **beginners** to understand basic **front-end web development concepts**.

---

## ✏️ Features
- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- 🗑️ Delete tasks when no longer needed  
- 🎨 Clean and simple user interface  
- ⚡ Fast and responsive  

---

## 🧠 How It Works
- 📥 User enters a task  
- ➕ Task is added to the list  
- ✅ Clicking a task marks it as completed  
- 🗑️ Delete button removes the task  

---

## 🛠 Tech Stack
- 🌐 HTML  
- 🎨 CSS  
- ⚙️ JavaScript  

---

## ▶️ How to Run
1. 📂 Download or clone the repository  
2. 🌐 Open `index.html` in a web browser  
3. ✍️ Start adding and managing your tasks
